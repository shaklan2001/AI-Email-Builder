Before generating a workflow, the AI should create and display a Campaign Brief.

## Why

Users should be able to verify that the AI correctly understood their campaign before workflow generation begins.

This reduces incorrect workflows and improves trust.

## New Flow

User Prompt

↓

AI Collects Information

↓

Campaign Brief

↓

User Approval

↓

Workflow Generation

↓

Email Generation

↓

Review

↓

Activate

## Campaign Brief

Display:

Campaign Name

Business Goal

Target Audience

Product / Service

Tone

CTA

Attachments

Landing Page

Workflow Strategy

Example:

Campaign Name:
AirPure Pro Product Launch

Goal:
Book Product Demos

Audience:
Homeowners and Apartment Owners

Tone:
Professional and Friendly

CTA:
Book a Free Demo

Follow-Up Strategy:
Wait 3 Days
Send Follow-Up If No Reply

Reply Strategy:
Send Demo Scheduling Email

## User Actions

Allow:

- Looks Good
- Edit Campaign Details

If user selects Edit:

AI continues asking questions.

If user selects Looks Good:

Generate workflow.

## Workflow Generation Rule

Workflow generation must not begin until the campaign brief is approved.

## Check When Done

- Campaign brief generated
- User can review brief
- User can edit brief
- Workflow generation waits for approval
- User confidence improved
